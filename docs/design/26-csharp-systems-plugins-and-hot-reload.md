# Trusted C# modules, generated registration, and restart

[Terminology and reading conventions](01-terminology-and-reading-guide.md).

## 1. Module entry and trust

`IEngineModule` registers services, component schemas, systems/stages, asset codecs/importers, editor properties and content validators through a bounded `ModuleRegistry` during host construction. Registration is typed and dependency-ordered; module manifest `Guid`/version/engine application programming interface (API) range/dependencies/capabilities, license/signature/trust origin. Duplicate schema/system/service or dependency cycle fails construction before any world runs.

Registration/candidate migration may produce metadata/staged owned data only; it cannot open devices, start threads, perform external I/O or mutate the active module/world. Trusted module code must honor this contract; an in-process candidate context is not a security boundary capable of preventing malicious side effects. `Start` services only after complete registration/admission, with explicit cleanup ownership if startup fails.

Application uses compiled C# systems with own state; no mandatory interpreted scripting language or serializing arbitrary object graphs. Module cannot change frozen stage graph midway through a live tick. `Standard` services supplied explicitly by host/module context, not global singleton lookup.

Only explicitly trusted modules compiled into the selected artifact execute. A generated registry is not a security boundary: trusted code can perform file/network/native operations. Untrusted packages contain chapter [11](11-assets-import-streaming-and-packages.md)'s bounded inert data only; runtime assembly paths are not plugin admission. Do not offer a "sandboxed C# mod" by forbidding a few namespaces.

## 2. Runtime profiles

`AotPlayer`, `AotEditor` and `AotTools` are mandatory build profiles with the same applicable subsystem contracts, generated closed registries/codecs/component/editor metadata, and no dynamic managed assembly loading, runtime code generation or reflection-only generic discovery. These are build labels, not replacements for `Headless`/`Interactive`/`OffscreenNative` host profiles. Optional JIT comparison builds use the same closed registration and feature set; they do not enable additional module/reload capabilities.

Build source generators produce immutable schema/type registries, typed component-column factories, query/callable adapters, codecs, constructors and editor accessors with compile diagnostics. Each used generic instantiation is known to the build; unknown runtime schemas cannot instantiate an arbitrary CLR type. Explicit typed registration is permitted where generation adds no value. Root required metadata precisely and validate generated output in AOT/API/schema tests; broad trimming/reflection suppression is not qualification. Compiler-hosted generators remain build-time extensions, not runtime modules. `Headless` excludes device/window use while retaining canonical simulation and CPU extraction services.

Component generators and handwritten providers use the same public `ComponentSchema.FromCatalogue`, storage/path declarations, closed typed field-binding factories and `ComponentFactoryBinding<T>.Create<TAuthor>` entry. Registration captures the resulting binding once; neither a generator-only issuer nor runtime reflection may supply missing storage/reference mappings. Qualify generated and selected handwritten variants independently against the same pinned descriptors and independent expected bytes/values. The mandatory handwritten witness is an external public-only consumer with no friend/private issuer and no binding generation for its component; it compiles with warnings-as-errors and executes the real default/getter/presence/reference/read/restore/write paths in ordinary and NativeAOT lanes. Its immutable success/rejection producers are invoked only through the actual engine-issued scoped read binding. Compile availability alone does not qualify emitted roots or callback semantics.

The executable's selected feature/module manifest determines generated roots, not all namespaces available in a referenced package. Namespace co-location in `TerraFX.Runtime` does not register every renderer/UI/host adapter. Root the admitted factories, codecs, closed generics and metadata transitively; diagnose missing registrations/dependency conflicts before activation. Unselected native backends/editor/content tools/dev compilers are not player roots, and module initializers/static constructors cannot eagerly activate optional services. Preserve canonical headless simulation/CPU extraction while excluding native window/GPU/audio endpoint activation. Host options can disable activation without proving code was trimmed; publish inventories and actual reachable roots establish byte removal.

Generators resolve public namespaces to [29](29-project-setup-build-and-deployment.md#1-repository-and-assembly-dag)'s physical owners. The seven merged subsystem namespaces belong to Runtime, not same-named assemblies. Rebuild generated accessors/closed registration and every affected executable after that assembly identity changes; retain registered schema GUIDs/tags and do not infer a data migration or old binary compatibility from unchanged public names.

Editor property registrations include [25's quantity/unit/frame/reference metadata and typed converters](25-ui-text-and-editor-tools.md#authoring-presentation-and-conversion). Generation diagnoses incomplete or incompatible declared mappings; the same admitted mapping is used by inspectors and source adapters. No dynamic converter discovery, universal numeric/vector reinterpretation, or display-driven schema mutation is introduced. The registry freezes mapping semantics independently of per-editor display preferences.

Generated declarations/codecs/accessors preserve [02's integer domains](02-dotnet-api-memory-and-ownership.md#integer-types-and-boundaries), including signed negative/overflow checks, native-width CPU extents and explicit unsigned identity/mask exceptions. A wire `UInt32`/`UInt64` does not infer an unsigned CLR member; the accepted descriptor supplies both representation and semantic admission range. Unknown/incompatible range conversion is a generation/admission diagnostic, not an unchecked cast or silent default. Integer-signature changes require rebuilding linked modules and reviewing descriptor compatibility through the existing restart path.

Generated finite-domain checks consume `IsFinite().All()` masks over the complete declared component extent; a mask is not a scalar truth value and Vector3 has no fourth component. Typed unit converters preserve [07](07-spatial-coordinates-and-indexing.md)'s integer exponent/exact dimensional ratio until final rounding. Descriptor/code generation pins [10](10-binary-data-and-authoring-formats.md#versioned-name-uuid-recipe)'s UUIDv8 namespace/key/recipe assignments and explicit foundation-profile/tag/table versions; changing a hash algorithm cannot silently regenerate registered identities or select legacy profile meanings. Regenerate/rebuild affected modules and validate required migration coverage at the existing restart gate.

Generated geometry adapters use the safe-callable `AsSystem`/`AsTerraFX` interchange family rather than recreating raw reinterpretations. Where a reviewed generator must emit `Unsafe.BitCast`, it emits a narrowly scoped implementation `unsafe` block and verifies that implementation project's effective `AllowUnsafeBlocks` setting. It does not mark a proved public facade unsafe, require an unsafe consumer project or infer that today's BCL annotations are permanent. The separate updated-memory-safety lane checks generated bodies and actual caller-obligation propagation; baseline output remains ordinary C# 15.

C# 15's unions/closed hierarchies, whose reusable-API implications are documented in [Chapter 36](36-primary-sources-and-rationale.md), are not plugin extension contracts. Engine-owned public definitions use stable named types/status enums; application/module-local implementation may use newer syntax without requiring the engine to expose it. Any internal choice still obeys trimming, registration, allocation, and version rules. Roslyn generators/analyzers and generated interop are qualified on the pinned compiler and optional updated-memory-safety lane; enabling that lane does not authorize an unsafe signature family or dynamic ahead-of-time (AOT) loading.

The finite M03 descriptors/defaults/ordered rules and compiled registrations are normative in [10](10-binary-data-and-authoring-formats.md#22-m03-content-schema-and-package-binding). Author models, contextual native codecs and World-bound Entity/state bindings have distinct rooted dispatch; Physics asset bridges are generated in Integration or permitted offline tools, never Physics-to-Assets. Activation admits exact tuples and never an implicit latest/additive minor. Any owner-specific conversion requires its own explicit contract and compiled consumer; no generic migration catalogue is implied. Required fields are always encoded; author defaults do not repair missing bytes, and this edition has no Record/FA/RA default facility or post-Restore canonical repair.

## 3. Data reload and managed-code restart

Shared callable registrations preserve IAction/IFunc/IReadOnlyRefFunc argument passing and concrete scoped-ref state across generated buffers/chains/chunks/physics adapters. Selected closed ObjectPool<T>/policy/action instantiations and Angle/source binding converters are explicit roots; no runtime generic closure or reflective activation is introduced. Generate source-only AuthoringAngleDefinition1 validation/persistence in tools/editor artifacts without adding a runtime geometry wire kind or rooting editor converters in players. The callback protocol replacement is a public source/API break requiring consumer/module rebuild; unchanged argument types do not preserve old interface binaries. Existing schemas/profiles/UUID assignments are not regenerated.

The framework cleanup rebuilds roots and source-binding baselines for IFunc/IReadOnlyRefFunc, six audio Async names, optional final cancellation tokens, nonnullable bus outputs and MaybeNull codec outputs. Preserve schema-dependent successful null policy; enum status is not a bool-flow annotation. Generated numerical declarations/adapters retain narrow operator and char/UTF-8 formatting protocols, StringSyntax metadata and the named SinCos pair without changing backing rows, raw values or wire recipes. The transitive declaration catalogue includes tag/options/session/UI snapshot issuers and lifetimes; incomplete descriptors fail generation instead of producing public parameterless placeholders. These API/metadata edits require consumer/module rebuild, not a new layout, package, coordinate, spatial, UUID or serialized-data profile.

Asset, shader, material and other registered pure-data versions retain their existing boundary activation/retirement protocols. Their reload does not require managed IL loading, recompilation or replacement of runtime type identity.

A managed-code or generated-registry change reports `RestartRequired`; it is not an in-process hot reload. The baseline is rebuild plus explicit relaunch of every affected executable, including the editor when its linked module/accessor registry changes. A replaceable preview-worker architecture is not a version-one requirement.

Build the candidate into a distinct versioned output directory off the owner thread. Validate its artifact digests, closed registry, API/schema/profile/dependency manifests and required migration identities/coverage before stopping the active application; a failed build/admission reports `BuildFailed`/`Rejected` and leaves it active. Do not overwrite an executable/native library still in use or execute candidate startup services during manifest validation.

Before an approved restart, save unsaved authoring documents and optional reloadable state through the existing transaction protocols at a committed boundary. Stop play/world admissions, join jobs/subscriptions/callbacks, invoke module `Stop` and owner cleanup outside engine locks, and retire actual native consumers. Failed save or ownership-retaining shutdown prevents a successful restart claim; timeout never authorizes DLL unload or freeing live storage.

After successful shutdown, relaunch the selected artifact with explicit host/device profiles and validate/load a committed checkpoint through registered `Standard` migrations into a fresh world. Remap ephemeral handles from stable IDs. A changed code/registry/runtime profile does not inherit `StrictLocal` continuation. Failed startup/load, including migration execution, reports failure and retains the prior artifact/checkpoint for an explicit relaunch; it cannot roll back already performed external effects or fabricate a running old process.

## 4. Version and state rules

Chapter [06](06-owned-geometry-and-numerics-interchange.md)'s owned geometry changes nominal public API types despite matching base class library (BCL) component layouts. Module admission checks engine API-major and `EngineGeometryBinary32Rows2` before world creation; rebuild old BCL-typed modules rather than pretending a bitcast supplies binary API compatibility. The closed registry uses the selected artifact's single `TerraFX.Core`/type identity, not private duplicate module copies. Same-left-handed (LH) scalar schema migrations are explicit `Standard` data migrations, distinct from coordinate changes and strict continuation.

Schema major breaking changes need registered migration (`oldGuid`/version -> new). An added optional field with a documented default is a compatible minor data migration; a removed/changed field cannot be guessed. Ephemeral `Entity`/Body/Voice/graphics processing unit (GPU) handles are recreated and remapped from stable IDs, not persisted through assembly/world replacement.

Module-owned random state/timers are explicitly serializable for replay. User background threads/tasks must register ownership/cancellation and join on `Stop`; unregistered work is unsupported plugin behavior and reported by available diagnostics, not something engine guarantees to discover.

Acceptance requires cyclic/duplicate/missing generated registration, forbidden late mutation, trust separation, NativeAOT player/editor/tool execution, dynamic managed loading refusal, data/shader reload without JIT, failed candidate admission retaining the active application, explicit code-restart requirements, stable-ID checkpoint remap, live callback/native-consumer drain, failed-save/shutdown/startup transparency and no cross-profile strict-continuation claim. Optional JIT comparisons test the same features rather than a privileged development mode.
