# Implementation roadmap

This page tracks current milestone state and open gates; it is not implementation history. Milestone scope, dependencies, and acceptance criteria are defined in the [design roadmap](../design/35-implementation-roadmap.md). Build and qualification commands are in [Building](Building.md). Use Git history for provenance and ignored artifacts for detailed test output.

| Milestone | Status | Current state and remaining gates |
|---|---|---|
| M01 - Repository and implementation readiness | Complete | Repository and first-unit prerequisites are established. |
| M02 - Core ownership, numerics, and spatial data | Qualification pending | Selected implementation and managed regressions are complete. Target-profile NativeAOT and performance/capacity qualification remain. |
| M03 - Worlds and native semantic content | In progress | M03-A selected World, Scene, control, provider, and generator work is implemented. Production Save and selected Assets/Scene/Mesh/Skeleton/Clip producers, package-backed binding validation, static BindPose extraction, and restore-side stable identity ledger reconstruction are implemented. Standard Branch Save→PrepareLoad→CommitLoad restores package-backed Scene/ECS/resource/system/attachment/clock/control state, validates fresh canonical Count/Write output before publication, publishes a restored marker and identity remap, and supports standalone and typed host-schedule replacement with separately reported old-World retirement. Scene expansion and measured Sprite/Mesh render-resource-bundle storage are pre-admitted before captured external-domain closure; active Sprite and Mesh Scene restore/remap witnesses pass. Target-bound capture is mediated by an Entities-owned WorldConstructionPlanControl and transfers operation credits while holding the exact target gate. Engine-default close ownership transfers through a separately charged, single-use handoff bound to the exact current and successor bindings. Other restore intents remain unsupported. Remaining: complete Chapter 12/27/30 retained-history, playback, lifetime, and retirement/quarantine controls; complete applicable M03 qualification. |
| M04 - Native host, input, and presentation resources | Implementation complete | M04-owned Windows/Linux Platform, recipient routing, text/clipboard, D3D12/Vulkan graph and WSI paths, snapshot residency, and host recovery are implemented. Native graphs exercise four color attachments, later-pass copies to and from rendered attachments, sixteen sampled images with eight sampler bindings, eight-UBO native pipeline layouts across Frame/Material groups, and cross-slot transient allocation retention; staging ranges are fence-owned and native descriptor heaps exercise exhaustion, rollback, and reuse. Color/depth attachment actions are supported for the admitted shape. Windows keyboard routing and the focused physical Xbox GameInput button/device-removal/reconnect lifecycle are verified. The UI-owned capture integration check and real driver/OS loss, submitted-work/presentation timeout, and uncertain-work retirement observations move to M09; the production UI provider is owned by M08. Physical TSF IME testing is deferred with user acceptance unless issues are reported. WSLg uses llvmpipe and has no physical evdev input. |
| M05 - Renderer, animation, and source adapters | In progress | CPU kernels/layout, offline shader compilation/reflection, package-backed static Mesh/Sprite extraction, Atlas residency/batching, built-in Sprite C0, opaque/masked/blended PBR Mesh C0, supported texture/vertex-color inputs, unshadowed point lights, and static BindPose skinning are implemented. The bounded GLB/OBJ adapters produce deterministic EPKG2 packages. Directional cascade CPU kernels exist; native shadow passes remain unimplemented, and spot lights remain refused pending their contracted lighting/shadow paths. Built-in Mesh and Sprite passes compose in camera order across multiple cameras on one shared HDR target and tone-map once. Dynamic animation/particles, expanded renderer features, and applicable native/AOT/consumer qualification remain. |
| M06 - Standalone custom physics | Not started | Dimensional cooking, solver, queries, CCD, and checkpoint qualification remain. |
| M07 - Custom audio and subsystem integration | Not started | Custom mixer/endpoints and integrated subsystem observations remain behind their applicable prerequisites. |
| M08 - Editor, extensibility, and release qualification | Not started | Editor/tooling, closed modules, M08-owned acceptance, and release measurements remain. The production UI disposition provider needed by the deferred M04 capture check is owned here. |
| M09 - Missing validation | Qualification pending | Close the deferred M04 UI-capture integration and real native loss/timeout/uncertain-retirement observations after the production UI provider and safe native stimuli are available. These observations do not block unrelated implementation. Physical TSF IME testing remains deferred by user acceptance. |

## Next work

1. Close the remaining M03-B retained-history, playback, lifetime, and retirement/quarantine ownership against Chapters 12/27/30. Standard Branch Load and active package-backed Sprite/Mesh Scene replacement are implemented; other restore intents remain unsupported.
2. Keep live animation and particles behind their owner contracts. Extend renderer features only with their approved producer/consumer contracts; implement native shadow passes only against the existing Chapter 19 RenderArea and Chapter 21 shadow contracts.
3. Qualify real native/AOT/public consumers separately from M05 managed implementation and M08 release qualification.
