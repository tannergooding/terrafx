# Implementation roadmap

This page tracks current milestone state and open gates; it is not implementation history. Milestone scope, dependencies, and acceptance criteria are defined in the [design roadmap](../design/35-implementation-roadmap.md). Build and qualification commands are in [Building](Building.md). Use Git history for provenance and ignored artifacts for detailed test output.

| Milestone | Status | Current state and remaining gates |
|---|---|---|
| M01 - Repository and implementation readiness | Complete | Repository and first-unit prerequisites are established. |
| M02 - Core ownership, numerics, and spatial data | Qualification pending | Selected implementation and managed regressions are complete. Target-profile NativeAOT and performance/capacity qualification remain. |
| M03 - Worlds and native semantic content | In progress | M03-A selected World, Scene, control, provider, and generator work is implemented. Production Save and selected Assets/Scene/Mesh/Skeleton/Clip producers, package-backed binding validation, static BindPose extraction, and restore-side stable identity ledger reconstruction are implemented. Standard Branch Save→PrepareLoad→CommitLoad restores package-backed Scene/ECS/resource/system/attachment/clock/control state, validates fresh canonical Count/Write output before publication, publishes a restored marker and identity remap, and supports standalone and typed host-schedule replacement with separately reported old-World retirement. M03-B independent World-use U/D/W accounting, the Scene preparation cap, and external-binding option-copy claims are implemented and covered by Runtime Debug/Release tests. Remaining: a stable precreated Scene preparation root, full planner/cache/Rendering/measurement workspace funding, retained receiver release after World close, failed-cleanup/quarantine ownership, finite producer/publication lifetime proof, and complete applicable M03 qualification. Other restore intents remain unsupported. |
| M04 - Native host, input, and presentation resources | Implementation complete | M04-owned Windows/Linux Platform, recipient routing, text/clipboard, D3D12/Vulkan graph and WSI paths, snapshot residency, and host recovery are implemented. Native graphs exercise four color attachments, later-pass copies to and from rendered attachments, sixteen sampled images with eight sampler bindings, eight-UBO native pipeline layouts across Frame/Material groups, and cross-slot transient allocation retention; staging ranges are fence-owned and native descriptor heaps exercise exhaustion, rollback, and reuse. Color/depth attachment actions are supported for the admitted shape. Windows keyboard routing and the focused physical Xbox GameInput button/device-removal/reconnect lifecycle are verified. The UI-owned capture integration check and real driver/OS loss, submitted-work/presentation timeout, and uncertain-work retirement observations move to M09; the production UI provider is owned by M08. Physical TSF IME testing is deferred with user acceptance unless issues are reported. WSLg uses llvmpipe and has no physical evdev input. |
| M05 - Renderer, animation, and source adapters | In progress | CPU kernels/layout, offline shader compilation/reflection, package-backed static Mesh/Sprite extraction, Atlas residency/batching, built-in Sprite C0, opaque/masked/blended PBR Mesh C0, supported base/emissive/packed metal-rough-occlusion textures and vertex colors, static BindPose skinning, single-sided opaque tangent-space normal maps, point lights, four-cascade directional shadows, and spotlight lighting with four priority-selected shadow slots are implemented. Chapter 20's skinned-normal fallback is shader-compiled for both backends; its degenerate weighted case awaits a live animated-palette producer. World-produced receiver occlusion is observed through D3D12 and Vulkan Mesh C0 graphs. The bounded GLB/OBJ adapters produce deterministic EPKG2 packages, and their package production/binding paths are validated. The selected package-backed Mesh C0 consumer path currently reaches `SceneLoader.PrepareAsync` and is blocked by the fail-closed `PreparedScene` footprint guard before extraction/submission; its native pixel observations require requalification after the M03-B producer gates close. Chapter 19 scopes RenderArea to each pass's attachments, and both backends support atlas-sized depth-only areas independent of graph output. Built-in Mesh and Sprite passes compose in camera order across multiple cameras on one shared HDR target and tone-map once. Public-only Headless and D3D12/Vulkan offscreen consumer cases exist, but those Scene-dependent observations are not current acceptance evidence while the preparation guard remains closed. The skinned-normal diagnostic route remains unqualified: the public result carrier is not accepted API, and the full 32-MiB preparation/recording and 16-MiB completion ledgers remain NO-GO. Core readback uses a Graphics-preclaimed, Core-accounted buffer handoff; bounded recording/freeze/prequeue refusal, profile-bound pipeline-use cohorts, command-root detachment/quarantine, and a fixed 256-entry FIFO owner queue with nonwaiting diagnostic refusal are implemented. Graphics preflight has exact-capacity buffer/texture/pass import and alias-barrier indexes with a combined constructor precheck; this is only component accounting, not whole-graph admission. Remaining validation maps/sets, backend-retained capacity, owner controls, payload aliases, quarantine, and completion storage are unqualified. Native Mesh 2.0/Material 2.0 authoring, package cooking, and the standalone exact CPU LOD-selection kernel are implemented; per-camera LOD history and Scene consumption remain gated. Cosmetic-particle schemas, package cooking, deterministic CPU kernels, and a private emitter component are implemented; a compile-only credit-owner candidate exists, but World registration/pool/lifetime/rendering remain gated. Dynamic animation/root motion remains gated on the reviewed pre-construction registration/state/extraction extension. Picking's private CPU membership/pixel/ID-map helpers are implemented; visual picking still requires complete owner data/API contract, real Scene provenance, and M04 R32UInt/readback. Sampled cube sky and its environment pass are explicitly deferred for 0.1, preserving the sampled-cube refusal. Broader native/AOT/public-consumer qualification remains. |
| M06 - Standalone custom physics | Not started | Dimensional cooking, solver, queries, CCD, and checkpoint qualification remain. |
| M07 - Custom audio and subsystem integration | Not started | Custom mixer/endpoints and integrated subsystem observations remain behind their applicable prerequisites. |
| M08 - Editor, extensibility, and release qualification | Not started | Editor/tooling, closed modules, M08-owned acceptance, and release measurements remain. The production UI disposition provider needed by the deferred M04 capture check is owned here. |
| M09 - Missing validation | Qualification pending | Close the deferred M04 UI-capture integration and real native loss/timeout/uncertain-retirement observations after the production UI provider and safe native stimuli are available. These observations do not block unrelated implementation. Physical TSF IME testing remains deferred by user acceptance. |

## Next work

1. Close the remaining M03-B Scene preparation root, workspace/receiver, cleanup, and producer-publication lifetime gates without reducing P or weakening World/domain ceilings.
2. Complete the M05 diagnostic byte ledger and whole-graph refusal; remaining Animation/particle/LOD/picking consumers stay gated on their real producers and owner contracts.
3. Qualify real native/AOT/public consumers separately from M05 managed implementation and M08 release qualification.
