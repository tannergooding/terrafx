### New Rules

Rule ID | Category | Severity | Notes
--------|----------|----------|--------------------
TFX0001 | Style | Warning | Require a block for every nonempty switch section.
TFX0002 | Style | Warning | Order type members by category, staticness, accessibility, and name.
TFX0003 | Style | Warning | Enforce blank-line spacing after type openings and between brace-terminated sibling statements or members, switch sections, and before compound control-flow statements.
TFX0004 | Style | Warning | Require exactly one top-level type declaration per C# source file.
TFX0005 | Style | Warning | Require auto-implemented property declarations to fit on one line.
TFX0006 | Style | Warning | Keep single-paragraph XML documentation elements on one line and align multiline comment markers.
